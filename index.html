Log in

GitHub storage

Your timesheet is saved as a JSON file in a GitHub repository. Every save is a commit, so you can see and restore any earlier version. Changes are also kept in this browser, so you can keep working offline.

  1. Create a private repository for the data, for example timesheet-data. Tick "Add a README" so it has a main branch.
  2. Create a fine-grained token. Under "Only select repositories" pick that repository, and set Contents to "Read and write".
  3. Paste it here. The token stays in this browser and is only sent to api.github.com.

Password login

Choose one password to open your timesheet on any device or browser without entering the GitHub details again. The details above are encrypted with this password and saved as config.json next to the app.
